LEGO® SPIKE™ Prime

Базовый & Продвинутый уровень

Флагманский образовательный набор LEGO, объединяющий яркие детали, мощный хаб с 6 портами, датчики и моторы. Позволяет быстро собирать и программировать автономных роботов для решения инжиниринговых задач.

Возраст: 10–14 лет
Языки: Scratch / Python
Соревнования: WRO, FLL
Датчики: Гироскоп, Цвет, Ультразвук
Блочное программирование Текстовый Python Спортивная робототехника Механика

Arduino & Электроника

Программирование & Схемотехника

Основа настоящей микроэлектроники. Ученики проектируют электрические схемы, пайку и макетирование, работают с контроллерами Arduino Uno/Nano, сервоприводами, дисплеями и внешними модулями.

Возраст: 12+ лет
Языки: C++ (Arduino IDE)
Соревнования: STEM-Fest, IT-проекты
Плата: ATmega328P
Схемотехника Язык C++ Датчики и реле Умный дом / IoT

R:ED X (RED Robotics)

Соревновательный комплекс

Профессиональные образовательные наборы с прочными конструктивными элементами, мощными моторами и контроллером R:ED. Идеально подходят для подготовки к международным фестивалям по спортивной робототехнике.

Возраст: 10–16 лет
Языки: Scratch / Python
Соревнования: R:ED FEST
Движение по линии / Кегельринг
R:ED Code Скоростная езда по линии Инженерная сборка Автономные алгоритмы

Makeblock Ultimate 2.0

Металлическая робототехника

Флагманский конструктор 10-в-1 на базе анодированного алюминия. Позволяет собирать тяжелые механизмы: роботы-манипуляторы, гусеничные платформы, шагающие конструкции и 3D-сканеры.

Возраст: 12–17 лет
Языки: mBlock / Python / C++
Соревнования: MakeX, Научные проекты
Плата: MegaPi (Arduino)
Металлические детали Приводные шасси Манипуляторы Прикладная инженерия
